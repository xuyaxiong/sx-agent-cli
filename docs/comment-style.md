## 五条

1. **模块头分固定小节** —— 标题**只用这五个**，别自创第六个：

   | 小节 | 写什么 | 必须有？ |
   |---|---|---|
   | `## 这个文件是什么` | 一段话说清职责、它在链路里的位置 | ✅ **必须有** |
   | `## 设计原则（不变量）` | 这个模块不许被破坏的规矩 | 可选 |
   | `## 关键取舍` | 选了什么、放弃了什么、为什么 | 可选 |
   | `## 遗留问题` | 已知欠账 | 可选 |
   | `## 沿革（改过什么、为什么改）` | **所有历史只许写在这里** | 有历史就得有 |

2. **表项 / 常量 / 函数上的注释只留两样**：这条规矩是什么 ＋ **一句话**为什么。
   长叙述（多段实测故事、改名经过）一律进「沿革」，正文里用 `〔沿革 N〕` 指过去。
3. **版式分三类，一眼分得清**：
   - `# ──────────── 分组名 ────────────` = **导航**（这一块是讲什么的）
   - `#:` / `#` 紧贴在被管的那行**上方** = **规则**（这条为什么长这样）
   - `〔沿革 N〕` = **引用**（历史在哪）
4. **同一条规矩只在一处展开**，别处一行引用（"一套，别分叉"）。
5. **日期只许出现在「沿革」小节里**（`20\d\d-\d\d-\d\d`）。

## 沿革的编号规矩

- 编号是**引用锚**：正文里写 `〔沿革 N〕`。
- **只追加、不改号**，新条目加在**末尾**（所以是**正序**：老条目号小）。
  ⚠️ 中间插一条会让**所有引用错位** —— 所以不许插；要补旧事就新起一号，注明"补记"。
