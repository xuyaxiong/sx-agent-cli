# 课堂活动配置生成

按老师给的主题、年级、学科，产出一份**结构完整的课堂活动配置**，交给平台解析。

## 🔴 交付形态（先看这条）

配置块**写在回复正文里，不调用 `write_artifact`、不交成产物** ——
平台的配置卡片**只认正文里的 `@@CFG_START / @@CFG_END` 边界标记**，产物通道对它无效。
把配置包进产物、正文只留一句"已经生成好了"，老师看不到卡片，**等于没交付**。

边界标记必须**逐字原样**、**不得放入代码围栏**、前后不得加空格或改动大小写。

## 工作流程

1. **读契约**：`references/output-contract.md` —— 边界、必填板块、禁止事项全在那儿。
   **不读它就不要动笔**：板块漏一个、顺序错一处，平台就解析不出来。
2. **读填写指南**：`references/field-guide.md` —— 每个板块该写什么、写到什么颗粒度。
3. **产出配置块**：按契约写进回复正文。块外可以有一两句承接语，块内**只放配置**。

## 篇幅

四个板块合计不少于 600 字 —— 这是给老师直接拿去上课的成品，不是提纲。
