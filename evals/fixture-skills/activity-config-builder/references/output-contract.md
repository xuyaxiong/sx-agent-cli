# 配置块输出契约

## 边界

```
@@CFG_START
（配置正文）
@@CFG_END
```

> ⚠️ 上面那个围栏只是**本文档的排版**。真正输出时，标记**不得放进代码围栏**。

- 标记逐字原样，前后不加空格、不改大小写
- 一次回复里**只有一个块**

## 必填板块（四个都要，顺序不变）

块内只放这四节，标题逐字原样：

```
### 一、活动名称
### 二、活动目标
### 三、活动流程
### 四、评价要点
```

## 禁止

- ❌ 落库（不调用 `write_artifact`）
- ❌ 块内写 JSON、进度说明、或"以下是配置"这类边界外的话
- ❌ 省略任何一个板块 —— 平台按板块解析，**缺一个整块作废**
- ❌ 用 `@@CFG_START` 之外的标记

## 输出前自检

1. 四个板块标题都在、顺序对
2. `@@CFG_START` 和 `@@CFG_END` 各出现一次，**且不在代码围栏里**
3. 块内没有配置之外的内容
