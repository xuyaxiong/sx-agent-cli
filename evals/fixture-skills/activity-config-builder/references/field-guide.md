# 板块填写指南

## 一、活动名称

一行，说清"**谁、在什么场景、做什么**"。
形如：`三年级数学《分数的初步认识》——分一分`

## 二、活动目标

- 写**学生能做什么**（可观察的行为），不写"理解""体会"这类不可观察的词
- 2–4 条，每条一行

## 三、活动流程

按时间顺序分步，每步写清三样：**学生做什么 / 老师做什么 / 大约几分钟**。
4–6 步，覆盖导入到收尾。

## 四、评价要点

- 每条写：**看什么 + 什么算达标**
- 至少 2 条，与活动目标**一一对应**

## 颗粒度

老师拿着它就能上课 —— 不写"通过活动培养学生的能力"这种空话。
